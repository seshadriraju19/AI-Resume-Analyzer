# Software Requirements Specification (SRS)

## Project

AI Resume Analyzer

---

# 1. Functional Requirements

The system shall allow users to:

- Register an account
- Login securely
- Upload PDF resumes
- Analyze resumes using AI
- Generate ATS compatibility score
- Detect missing keywords
- Detect missing skills
- Suggest resume improvements
- Download analysis report
- View previous resume analyses
- Delete previous analysis
- Update user profile
- Logout securely

---

# 2. Non-Functional Requirements

The system should:

- Respond within 5 seconds
- Support multiple users
- Store data securely
- Have a responsive UI
- Follow REST API architecture
- Be easy to maintain
- Be scalable for future features

---

# 3. User Roles

## Candidate

- Register
- Login
- Upload Resume
- View Reports
- Download Reports

## Admin (Future)
